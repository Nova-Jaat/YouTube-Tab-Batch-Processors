## 🎯 7-Day Sprint Goal
Clone an open-source Google Maps scraper, extract 1,000 clean leads in your city, and sell the verified dataset to a local agency for $150.

---

## 🛠️ Step 1: Execution Setup
1. Clone a verified open-source scraper repo from GitHub (e.g. `gosom/google-maps-scraper` or Puppeteer scraper).
2. Run extraction query: `category: "HVAC contractor", location: "Phoenix, AZ"`.
3. Extract: Business Name, Address, Phone, Website, Rating, Number of Reviews.

---

## 📊 Step 2: Data Cleaning & Enrichment
1. Import CSV to Google Sheets.
2. Filter out rows missing phone numbers.
3. Add a column: `Has SSL Certificate?` and `Mobile Friendly?` (identifies high-probability web design prospects).
4. Package the clean spreadsheet with professional formatting.

---

## 💼 Step 3: Pitching Local Marketing Agencies
```text
Hey [Agency Owner],

I noticed your agency specializes in lead generation for home-service contractors.

I just extracted and verified a clean dataset of 1,200 licensed HVAC contractors in Phoenix with verified phone numbers, website audit scores, and review metrics.

I've attached 25 sample leads for free. If you want the full 1,200 dataset for your outbound team, it's a flat $150.
```
