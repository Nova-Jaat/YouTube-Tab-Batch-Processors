## 🎯 7-Day Sprint Goal
Use conversational AI code generation (Grok, Claude, or Cursor) to build an interactive web calculator, deploy to Vercel, and pitch it to local businesses for $400.

---

## 🛠️ Step 1: The Spec-Driven Prompt
Copy and paste this prompt into Grok or Claude:

```text
You are an expert full-stack developer.
Build a single-file interactive 'Commercial Office Cleaning Cost Calculator' using HTML, Tailwind CSS, and vanilla JavaScript.
Requirements:
1. Inputs: Square footage (slider: 1,000 to 50,000 sq ft), Frequency (Daily, 3x/week, Weekly), Add-ons (Window cleaning, Floor waxing, Sanitization).
2. Real-time dynamic price calculation display with breakdown.
3. Clean, modern SaaS aesthetic with dark mode support.
4. Contact lead capture form at the bottom: Name, Business Name, Phone, and 'Email My Detailed Quote' button.
5. All code must be self-contained in a single index.html file with working logic.
```

---

## 🚀 Step 2: Instant Deployment on Vercel
1. Create a GitHub repo: `commercial-cleaning-calculator`.
2. Push `index.html`.
3. Connect GitHub to Vercel.com (Free tier) -> Click Deploy.
4. You now have a live, HTTPS website URL in 60 seconds.

---

## 💼 Step 3: Pitch to 10 Local Cleaning Companies
Send the live Vercel link:
*"Hey [Owner], I noticed your website doesn't offer an instant quote estimate for office managers. I built this interactive commercial cleaning calculator tailored for your city: [Vercel Link]. If you want this embedded on your website with your branding, I can install it this week for $350."*
