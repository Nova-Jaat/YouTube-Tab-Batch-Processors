## 🎯 7-Day Sprint Goal
Set up a YouTube Shorts and TikTok channel using only a smartphone, produce and schedule 14 videos, and add a monetized affiliate link in the comments.

---

## 🛠️ Step 1: Install Mobile Tool Stack
1. **Claude Mobile App** (App Store / Google Play).
2. **CapCut Mobile** (Free).
3. **Pexels Mobile App** (For downloading free 4K vertical background clips).

---

## 📝 Step 2: Mobile Script Prompt for Claude
Prompt Claude on your phone:
```text
Write 5 viral 25-second YouTube Shorts scripts in the 'Psychological Life Lessons' niche.
Format:
- 0-3s Hook: 'Most people realize this truth way too late in life...'
- 3-18s Body: 3 deep philosophical points that challenge common assumptions.
- 18-25s Outro: 'Follow for daily mental models. Check pinned comment for the full reading list.'
```

---

## 🎬 Step 3: CapCut Mobile 7-Minute Assembly
1. Open CapCut -> New Project -> Import vertical b-roll clip.
2. Tap `Audio` -> `Text to Speech` -> Select a natural deep voice.
3. Tap `Text` -> `Auto Captions` -> Select dynamic template with yellow text highlight.
4. Export at **1080p, 60 FPS**.
5. Upload to YouTube Shorts with a pinned comment: *"The 3 books that changed how I think: [Affiliate Link]"*.
