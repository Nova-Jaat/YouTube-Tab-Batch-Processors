## 🎯 7-Day Sprint Goal
Configure your local `.cursorrules` environment and build a production-grade contractor website in under 2 hours.

---

## 🛠️ Step 1: Save the Master `.cursorrules` File
In your project root, create `.cursorrules` with these exact instructions:

```text
You are an expert senior front-end engineer.
Stack: Next.js 14, Tailwind CSS, TypeScript, Lucide React icons.
Strict Rules:
1. Always write mobile-first responsive code (test breakpoints 375px, 768px, 1280px).
2. NEVER output placeholder comments like '// Add more items here' or '// TODO'. Write complete code.
3. Use Tailwind utility classes only. No inline styles.
4. Ensure all buttons have explicit hover and active focus states.
5. All images must include alt text and width/height.
6. The contact form must include client-side validation and visual error state handling.
```

---

## 🚀 Step 2: The 1-Shot Website Prompt
Open Cursor Composer (`Cmd+I` / `Ctrl+I`) and prompt:
```text
Build a complete, responsive one-page website for 'Apex Roofing Pros' in Dallas, TX.
Include:
- Sticky navbar with logo, emergency phone number, and 'Get a Free Quote' button.
- Hero section with high-converting headline, trust badges, and instant estimate form.
- 4-card Services section (Roof Replacement, Storm Damage Repair, Commercial Roofing, Gutter Installation).
- Customer Reviews section featuring 3 verified 5-star Google review cards.
- Clean footer with service areas, license info, and copyright.
Follow all .cursorrules standards.
```
