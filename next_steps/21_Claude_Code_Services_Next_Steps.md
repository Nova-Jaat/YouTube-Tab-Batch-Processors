## 🛠️ Step 1: Build the Invoice Parser with Claude Code
In your terminal, run Claude Code:
```bash
claude "Build a Node.js script that reads all invoice PDFs from a folder named /invoices, extracts Invoice Number, Date, Vendor Name, Total Amount, and Tax using the Anthropic API, and appends the extracted data to a Google Sheet using the googleapis npm package."
```
Test with 3 sample PDFs. Verify error handling for malformed invoices.
